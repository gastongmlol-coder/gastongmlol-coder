## Hola, soy Gastón 👋

Infraestructura y automatización en **Tecnovex** (Uruguay). Trabajo con IA como herramienta diaria: Claude Code y Codex para ordenar información, generar planos y construir herramientas internas.

### En qué trabajo

- **Organización documental** — método y herramientas en Python para ordenar un Google Drive corporativo grande por entidad (personas, vehículos, clientes), en lotes revisables y sin versionar nunca datos sensibles.
- **Planos CAD automatizados** — generación de croquis, láminas contractuales de sitios, topografía y modelos 3D con `ezdxf` y AutoCAD por consola (`accoreconsole`). Un mismo desarrollo produce el despiece 2D, el PDF A3 para taller y el modelo 3D, así no pueden contradecirse.
- **Forja** — generador de documentos comerciales (órdenes de compra, cotizaciones, remitos) que recalcula todos los totales desde los renglones y bloquea la emisión si algo no cierra.
- **Herramientas para Claude Code** — mods, hooks y skills propios para guardar reglas de trabajo y ver el estado de los proyectos de un vistazo.
- **AI Ops Lab** — servicios de automatización con IA, en armado junto a un equipo en Costa Rica.

### Herramientas

Python · ezdxf · AutoCAD · Google Drive API · Apps Script · Git (commits firmados) · Claude Code · Codex

### Cómo trabajo

Orden estricto y explicado: cada carpeta con su código, cada regla escrita, cada cambio verificable. Los datos del cliente se quedan con el cliente; lo que se versiona es el método.
